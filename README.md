# 🌦️ Weather Dashboard

A simple weather dashboard built using **basic HTML, CSS, and JavaScript**. It allows users to search for weather information for any city and displays the current weather along with a multi-day forecast using a weather API.

## Features

- Search weather by city
- View current weather conditions
- Multi-day weather forecast
- Switch between temperature units
- Responsive design
- Modern glassmorphism UI
- Hover animations and interactive effects
- Detailed weather information for each day

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## Project Structure

```
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

- Enter a city name in the search box.
- Select the preferred temperature unit.
- Click the search button to retrieve weather data.
- The application displays the current weather conditions.
- A forecast for the upcoming days is shown below.
- Users can view additional weather details for each forecasted day.
